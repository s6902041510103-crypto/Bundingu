# Landing exactly on Finish bounces back

A Player who rolls past Square 100 walks back the excess Squares (5 over becomes
2 short). Landing exactly on 100 is the only way in.

We chose the bounce over "clamp at 100" so the last ten Squares stay tense to the
very end, and over "end the game at the first Finish" so a class period is
bounded by a fixed number of Rounds rather than by luck.
