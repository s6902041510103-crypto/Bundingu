# Game length is chosen by the Host, questions are mocked

The Host picks 5, 10, 15 or 20 questions when creating a game; that number is the
Room's `totalRounds` and it bounds the lesson. The default is 10.

A fixed length was rejected because a teacher running a 20-minute slot and a
teacher running a full period need different games, and a teacher who cannot set
the length will not trust the tool. Questions themselves remain mock data in
Phase 1 — the form control is real, the question bank is not yet.
