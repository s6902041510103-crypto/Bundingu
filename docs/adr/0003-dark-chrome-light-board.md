# Dark chrome, light board

The app shell — header, sidebar, cards, buttons — is a deep indigo/violet dark
theme with glass panels. The 10x10 Board itself is a light, softly graded surface.

The Board is the one thing every Player in the class reads at the same moment,
often from several metres away on a classroom projector. Dark UI reads as "game",
which is what we want for the product's feel; a dark Board would have crushed the
contrast of the square numbers and the animal tokens for the people furthest from
the screen.
